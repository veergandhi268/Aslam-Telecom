# Aslam Telecom — Official Website

Official high-converting, mobile-optimized website for **Aslam Telecom** (Shop No. 15, Municipal Market, Main Carter Road, Borivali East, Mumbai). Designed with a modern, high-tech aesthetic, tailored for Apple and flagship smartphone device care.

---

## 🌟 Key Features

1. **Modern High-Converting Tech Aesthetic**:
   - Electric Sky & Deep Sapphire blue visual identity.
   - Clean, lightweight responsive layout powered by Tailwind CSS, FontAwesome 6, and custom CSS.
   - Custom vector branding (SVG logo, favicon, service icons).

2. **Interactive Before & After Comparison Showcase**:
   - Touch-friendly, accessible sliding comparison modules for shattered screens, liquid damage board recovery, and display assembly restorations.

3. **Transparent Comparison Matrix**:
   - Compares *Aslam Telecom vs. Official Brand Centers vs. Untrained Corner Shops*.
   - Highlights prompt turnarounds, zero data wiping, precision micro-soldering, and free diagnostic checks.

4. **Mobile-First Experience**:
   - Full-height slide-in mobile navigation drawer (`100dvh`).
   - Sticky bottom action toolbar for phone users (*Direct Call*, *WhatsApp Chat*, *Book Repair*).
   - Touch-optimized tap targets and modal appointment booking.

5. **Store Location & Transit Guide**:
   - Exact address: **Shop No. 15, Municipal Market, Main Carter Road, Borivali East, Mumbai 400066** (Near Kasturba Police Station).
   - Walking transit guide from Borivali Railway Station (Platform 1 East Exit).
   - Verified contact number: **+91 98705 52602**.

## 🚀 Deployment on Vercel

3. Output Directory: `./` (Root).
4. Click **Deploy**.
